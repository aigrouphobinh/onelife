# Delivery Roadmap

All durations are planning estimates, not commitments.

## Phase 0 — discovery (weeks 1–2)
20–30 interviews; competitor review; privacy risk assessment; prioritized user journeys.

## Phase 1 — foundation (weeks 2–4)
Flutter app skeleton; navigation; theme; lint; CI; database schema and migration tests.

## Phase 2 — functional MVP (weeks 4–8)
Notes CRUD; local search; tasks CRUD; local notifications; export and deletion; accessibility.

## Phase 3 — quality beta (weeks 8–11)
Android device matrix; offline and restore testing; performance; security; consented pilot.

## Phase 4 — release (weeks 12–16)
Store assets, privacy policy, release signing, staged rollout, crash monitoring, support playbook.

## Phase 5 — enhancements
Share sheet; OCR; optional on-device AI; iOS parity; optional sync only after privacy review.

## Release gates
No milestone is complete without running app, passing automated tests, real-device evidence, and documented known limitations.
