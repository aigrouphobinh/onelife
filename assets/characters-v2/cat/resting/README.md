# OneLife Cat Resting · Glossy V2

This folder's `sheet_illustrated.webp` is a 12-pose source drawn for OneLife. The cat rests on a purple paw cushion, dozes, and gently wakes. It has **no alarm**. PNG, GIF and metadata are generated by `.github/workflows/glossy-character-animations.yml` using the pinned SHA-256 in `assets/characters-v2/animation_sources.json`. Technical CI and manual/phone visual QA are different gates; human QA pending.
